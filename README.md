# QRlytic – Level 2 (Web-Based QR Generator)

SmartQR is a customizable web-based QR Code Generator built using Python and Streamlit.  

It allows users to generate QR codes from text or URLs with real-time preview, downloadable output, and color customization.


### Core Features
- Generate QR codes from text or URLs
- Real-time QR preview
- Download generated QR as PNG
- Timestamp-based unique filenames
- Input validation and error handling


####  Customization Features
- Custom QR color selection
- Custom background color selection

### Architecture Features
- Modular project structure
- Reusable QR generation logic
- Separate UI and business logic layers

## Tech Stack
- Python
- VScode
